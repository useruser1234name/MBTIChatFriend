## 잘한 점 (Keep)

1. **중립 메시지 편향 발견**: `random.choice([0, 0, 0.5, 0.5, 1.0])` → 평균 +0.4의 은밀한 상승 편향을 발견하고 `0.0`으로 수정. 유저가 아무 말이나 해도 호감도가 오르는 문제 해결.
2. **현실적 감쇠 설계**: 7일 동결 → 주당 -2점 → 레벨 하한 방어의 3단계 설계로, 복귀 의지를 꺾지 않으면서도 방치를 방지
3. **비용 추적 경량 구현**: 기존 `record_event()` 인프라를 재사용하여 추가 테이블 없이 비용 메트릭 수집 완료
4. **재시도 토큰 누적**: 품질 게이트 재생성 시 토큰을 합산하여 실제 비용을 정확히 추적

## 개선할 점 (Try)

1. **비용 대시보드**: 수집만 하고 시각화가 없어서 실제 비용 추이를 파악하려면 SQL을 직접 쿼리해야 함
2. **openai/httpx 충돌**: `httpx<0.28` 제약과 `openai==1.51.0`이 충돌하여 `test_chat_service.py` 수집 실패 → 의존성 정리 필요
3. **감쇠 함수 테스트**: `calculate_affinity_decay()`와 `calculate_return_bonus()` 단위 테스트가 아직 없음
4. **파인튜닝 모델 비용**: 커스텀 모델의 비용 단가가 `_MODEL_COSTS`에 없어서 gpt-4o-mini 단가로 폴백됨

## 배운 점 (Learn)

1. **OpenAI Usage 객체**: `response.usage.prompt_tokens` / `completion_tokens`으로 토큰 사용량을 즉시 확인 가능. `usage`가 `None`일 수 있으므로 방어 코드 필수.
2. **복잡도 계산 순서**: `_classify_message_complexity()`를 모델 선택 전에 항상 호출하도록 리팩토링하면, 파인튜닝 분기와 무관하게 복잡도 기록 가능
3. **비용 단가 관리**: 모델별 단가를 딕셔너리로 관리하면 새 모델 추가 시 한 곳만 수정하면 됨
