# Web Chat MVP

## 목적

현재 제품의 핵심 가설은 "사용자가 직접 부여한 성격 페르소나와 MBTI 설정만으로 AI와 대화할 때 충분히 매력적인가"입니다. 이 문서는 Android 앱의 부가 기능을 확장하기 전에, 채팅 본질만 빠르게 검증하기 위한 웹 테스트 버전을 정의합니다.

## 이번 MVP 범위

- 웹 브라우저에서 바로 접속 가능한 단일 채팅 화면
- 사용자가 캐릭터 MBTI 선택
- 사용자가 성격/말투/관계감 등 페르소나 직접 입력
- 서버가 MBTI와 페르소나를 system prompt로 구성
- 최근 대화 일부를 함께 보내 자연스럽게 이어지는 채팅 테스트
- `OPENAI_API_KEY`가 없으면 목업 응답으로 UI 흐름 확인

## 제외하거나 보류하는 기능

아래 기능은 이번 웹 MVP에서는 의도적으로 제외합니다.

- Firebase Auth
- FCM/push notification
- Room/Android 로컬 저장
- ChromaDB 장기 기억
- 호감도/레벨업
- 일기/편지/리포트
- 이미지 생성/표정 세트
- 커뮤니티
- 결제/구독
- A/B 테스트와 품질 대시보드

기존 코드를 삭제하거나 대규모 주석 처리하기보다, 별도 MVP 라우터로 분리해 본질 검증 후 필요한 기능만 다시 붙이는 방향이 안전합니다.

## 실행 방법

```bash
cd server
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8090
```

브라우저에서 접속:

```text
http://localhost:8090/web-chat
```

## API

`POST /api/v1/web-chat/send`

요청:

```json
{
  "message": "오늘 너무 지쳤어",
  "mbti": "ENFP",
  "persona": "다정하고 장난기 있지만 힘들 때는 진지하게 들어주는 오래된 친구",
  "history": [
    { "role": "user", "content": "안녕" },
    { "role": "assistant", "content": "안녕, 오늘은 어떤 하루였어?" }
  ]
}
```

응답:

```json
{
  "reply": "그랬구나. 오늘은 웃기려고 애쓰기보다 네 얘기부터 들어줄게.",
  "mbti": "ENFP",
  "model": "gpt-4.1-mini",
  "mocked": false
}
```

## 다음 개발 순서

1. 실제 사용자 5~10명에게 MBTI/페르소나를 직접 입력하게 하고 대화 품질 피드백을 받는다.
2. 좋은 페르소나 입력 예시와 실패하는 예시를 수집한다.
3. 페르소나 입력을 자유형으로 둘지, 추천 템플릿을 제공할지 결정한다.
4. 대화 저장이 필요해지는 시점에만 DB 스키마를 붙인다.
5. 유지율 검증 전까지 이미지, 커뮤니티, 결제 기능은 붙이지 않는다.
