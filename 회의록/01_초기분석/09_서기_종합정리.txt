■ 회의 개요
  - 참석자: CTO/아키텍트, PM/고객만족도 전문가, 심리학/인문학 전문가,
    UI/UX 디자인 전문가, 시니어 개발자/데이터 아키텍트,
    데이터분석/AI모델 전문가, 비판 에이전트
  - 목적: MBTIChatFriend 프로젝트 종합 분석 및 개선 방안 도출
  - 진행 방식:
    1차) 각 전문가 독립 분석 보고서 작성 (01~06)
    2차) 비판 에이전트 교차 리뷰 (07)
    3차) 전문가 응답 및 교차 토론 (08)

■ 1차: 전문가별 분석 요약
================================================================================

[01] CTO & 아키텍트
- 서버: FastAPI + PostgreSQL(동기) + ChromaDB + OpenAI 기반
- 핵심 문제: 동기 DB(블로킹), 콘텐츠 필터 비활성, 인메모리 캐시 스케일링 한계
- LLM 비용: ~$600-800/일(1000 DAU) → 후에 과대추정으로 판명
- 5단계 로드맵: 안정화 → 최적화 → 스케일링 → 고도화 → 글로벌
- 보안 취약점 8개 식별, 우선순위 5개 즉시 실행 항목 제시

[02] PM & 고객만족도
- 타겟: MBTI에 관심 있는 18-30세 한국 여성
- 4개 페르소나(민지/수현/지호/은서) 정의
- 수익 모델: 무료/Basic(6,900원)/Premium(12,900원)
- 매출 예측: MAU 10만 기준 ~46M원/월
- 누락 P0 기능: MBTI 테스트, 자동 추천, 대화 칩
- KPI: D7≥40%, DAU/MAU≥0.3, 전환율≥12%

[03] 심리학 & 인문학
- 학술 기반: Bowlby 애착이론, Altman&Taylor 사회침투이론, Gottman 관계연구
- 핵심 우려: 기생적 관계 위험, 콘텐츠 필터 부재, 위기 개입 없음
- 호감도 시스템: 일방향 상승 편향 → 비현실적 관계 모델 학습 우려
- 평가: 안전장치 2/10, 윤리 4/10, 기생적 관계 관리 3/10
- 미성년자 보호, 위기 개입 프로토콜 긴급 필요

[04] UI/UX 디자인
- Nielsen 10대 원칙 기반 휴리스틱 평가
- 총점: 7.5/10
- 강점: Canvas 캐릭터 표현(12단계 파이프라인, 10감정), Material3, 마이크로인터랙션
- 문제: 접근성(contentDescription null, 터치타겟 28dp), 하드코딩 색상
- 성능 분석 부재 (AGSL Shader, Lottie, Canvas 저사양 기기 영향)

[05] 시니어 개발자 & 데이터 아키텍트
- ChatViewModel: 544줄 + 11개 의존성 (SRP 위반)
- DRY 위반: 메시지 준비 로직 3곳 중복
- 에러 핸들링: silent exception swallowing (치명적)
- Room DB: (characterId, createdAt) 인덱스 없음, FK 없음
- 테스트 코드 전무 (치명적)
- 보고서 분량 가장 짧음 (215줄)

[06] 데이터분석 & AI모델
- LLM 라우팅: binary simple/complex, ~75% 정확도, ~15% 과잉라우팅
- 프롬프트: 1,500-3,000 토큰 시스템 프롬프트, 16 MBTI × 6차원
- 품질 평가: 4축(mbti일관성/맥락관련성/감정자연도/참여품질) LLM-as-Judge
- 메모리: 3계층(요약/팩트/에피소드), 10턴 고정주기 문제
- 비용: ~$88.5/일(1000 DAU), 35% 최적화 여지
- 파인튜닝: 합성데이터 자기강화 위험, 10턴 고정 생성

■ 2차: 비판 에이전트 주요 지적사항
================================================================================

[보고서별 핵심 비판]
- 01 CTO: Android 분석 깊이 부족, GDPR 분석 부재, 클라이언트 보안 무시,
  비용 추정 7-9배 과대($600-800 vs $88.5)
- 02 PM: 법적 리스크 분석 없음, TAM/SAM/SOM 없음, 전환율 12% 과대,
  그룹채팅 기술난이도 과소평가
- 03 심리학: 긍정적 측면 분석 부족, 고전 이론 편중, 점수 기준 불명,
  호감도 후퇴가 리텐션과 충돌
- 04 UI/UX: 사용자 테스트 데이터 없음, 성능 UX 미분석, 색각이상 접근성,
  MBTI 모르는 사용자 우선순위 불일치
- 05 개발자: 분량 불균형(215줄), 서버 리뷰 깊이 부족, 보안 리뷰 미흡,
  소요 시간 과소평가
- 06 데이터: 한국어 NLP 특수성 무시, 프롬프트 인젝션 방어 없음,
  A/B 테스트 설계 부재, 16x16 궁합 비현실적

[공통 맹점 5가지]
1. 프로덕션 운영 인력/비용 분석 부재
2. 경쟁 환경 변화 대응 전략 없음
3. 데이터 삭제/잊힐 권리 메커니즘 없음
4. 장애 대응 및 SLA 미정의
5. 앱스토어 정책 준수 전략 없음

[통합 비판]
- 비용 추정 7-9배 불일치 (심각)
- MBTI 그룹 불일치 영향 구체적 예시 없음
- 콘텐츠 필터 활성화 후 오탐 관리 계획 없음
- "즉시 실행" 항목 합계 20개+ (비현실적)

■ 3차: 전문가 토론 핵심 내용
================================================================================

[비판 수용 사항]
- CTO: Android 분석 부족, GDPR 누락, 클라이언트 보안 누락 인정
- PM: 법적 리스크, TAM/SAM 누락 인정, 전환율 시나리오 분리(4/8/12%)
- 심리학: 긍정적 측면 분석 보충(Skjuve, Pentina 등 최신 논문),
  점수 채점 기준 명시
- UI/UX: 성능 UX 분석 누락 인정, 색각이상 개선안 제시,
  MBTI 모르는 사용자를 P0로 상향
- 개발자: 보고서 분량 부족 인정, ChatViewModel 리팩토링 구체 설계 제시
- 데이터: 한국어 NLP 분석 보충, 프롬프트 인젝션 방어 레이어 제안,
  궁합 계산을 4축×4규칙=16규칙으로 현실화

[주요 논쟁 및 합의]

논쟁1: LLM 비용 추정
- CTO: $600-800/일 → 과대 인정, $200-350/일로 수정
- 데이터: $88.5/일 → 보조 비용 미포함 인정
- 합의: 실 측정 기반 1주일 트래킹 필수

논쟁2: 호감도 후퇴 메커니즘
- PM: 이탈 가속화 우려 → 동결+복귀보너스 제안
- 심리학: 건강한 관계 모델 필요 → 완만한 하락 주장
- 합의: 7일 동결 → 주당 -2점(하한: 현레벨-1) → 복귀 시 50% 회복

논쟁3: AI 정체성 공개
- 심리학: EU AI Act 위반 우려
- 비판 에이전트: 앱 UI 표시만으로 충분
- 합의: "직접 물어보면 AI 인정, 캐릭터 연기 유지"로 프롬프트 수정

논쟁4: 그룹 채팅 우선순위
- PM: P1 → P2로 하향 수용
- CTO: 기술적 복잡도 높음 (비용 2-3배)
- 합의: P2 확정, MVP 제외

논쟁5: 데이터 삭제 시점
- CTO: Phase 2 설계
- 심리학: 출시 전 필수
- 합의 보류: 법무 검토 후 결정, 최소 "대화 기록 삭제"는 출시 전 구현

□ 콘텐츠 필터 활성화 + 오탐 allowlist

□ 위기 개입 키워드 감지
□ 기본 단위 테스트 (핵심 로직)
□ 대화 기록 삭제 기능

□ 비용 메트릭 수집 시스템
