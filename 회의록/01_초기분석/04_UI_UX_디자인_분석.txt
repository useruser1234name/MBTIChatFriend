1. 디자인 시스템 분석
================================================================================

1.1 컬러 팔레트
--------------------------------------------------------------------------------
프로젝트는 파스텔 톤 기반의 따뜻한 컬러 시스템을 채택하고 있다.
테마 파일에서 정의된 핵심 색상:
  - PastelPink: 분홍 계열 (스플래시, 로그인 배경 그라디언트)
  - PastelPurple: 보라 계열 (주요 악센트)
  - SoftMint: 민트 계열 (보조 색상)
  - SoftYellow: 노란 계열 (보조 색상)

채팅 버블 전용 색상이 별도로 분리되어 있어 일관성을 유지한다:
  - UserBubble / UserBubbleDark: 사용자 말풍선
  - AiBubble / AiBubbleDark: AI 말풍선
  - AccentRed: 에러 및 경고 색상

호감도 레벨별 색상 시스템 (HomeScreen CharacterCard):
  - Lv.1: #B0B0C0 (회색) -> 낯선 사이
  - Lv.2: #B5E8D5 (민트) -> 아는 사이
  - Lv.3: #FFF3B0 (노랑) -> 친한 친구
  - Lv.4: #FFB5C2 (분홍) -> 특별한 사이
  - Lv.5: #C9B1FF (보라) -> 연인

[평가] 색상 체계가 감정적 단계를 직관적으로 표현하고 있으나, 하드코딩된 Color()
값이 다수 존재한다. 테마 파일로 중앙화하면 유지보수성이 향상될 것이다.

1.2 타이포그래피
--------------------------------------------------------------------------------
MaterialTheme.typography를 전반적으로 활용하고 있다:
  - headlineMedium: 화면 제목 (SplashScreen, CharacterProfileScreen)
  - titleLarge/titleMedium: 섹션 제목
  - bodyLarge/bodyMedium: 본문 텍스트
  - labelSmall: 태그, 시간 표시

[우수] Material3 타이포그래피 스케일을 일관되게 사용하고 있다.
[개선필요] 일부 화면에서 직접 fontSize를 sp로 지정하는 경우가 있다
(SplashScreen의 22.sp, VoiceCallScreen의 20.sp 등). 커스텀 TextStyle을
테마에 등록하여 일관성을 확보해야 한다.

1.3 간격(Spacing) 일관성
--------------------------------------------------------------------------------
전반적으로 8dp 배수 체계를 따르고 있다 (8, 12, 16, 20, 24, 28, 32dp).
카드 패딩: 16dp~20dp로 비교적 일관적이다.
화면 수평 패딩: 16dp~28dp 범위로 화면별 차이가 있다.
  - HomeScreen: 16dp
  - DiaryScreen: 20dp
  - CharacterProfileScreen: 24dp
  - LoginScreen: 28dp

[개선필요] 수평 패딩 표준값을 정의하고 모든 화면에서 통일하는 것이 좋다.

1.4 Material3 활용도
--------------------------------------------------------------------------------
Material3 컴포넌트를 적극적으로 활용하고 있다:
  - TopAppBar, Scaffold, Card, Surface, AlertDialog
  - FilterChip (GalleryScreen MBTI 그룹 필터)
  - ModalBottomSheet (캐릭터 생성, 갤러리 상세)
  - LinearProgressIndicator (호감도 진행 표시)
  - FloatingActionButton (홈 캐릭터 추가)

MaterialTheme.colorScheme을 통한 다이나믹 컬러 활용이 잘 되어 있으며,
다크 모드 지원을 위한 isSystemInDarkTheme() 분기도 채팅 버블에 적용되어 있다.

[우수] M3 Design Language를 충실하게 구현하고 있다.


================================================================================
2. 사용성 평가 (Nielsen's 10 Usability Heuristics)
================================================================================

2.1 시스템 상태 가시성 (Visibility of System Status)
--------------------------------------------------------------------------------
[우수]
  - ChatScreen: "입력 중..." 텍스트와 TypingIndicatorBubble로 AI 응답 상태를 표시
  - VoiceCallScreen: 상태 인디케이터 (대기 중/녹음 중/처리 중/재생 중) 색상으로 구분
  - 호감도 LinearProgressIndicator로 관계 진척도를 실시간으로 표시
  - 오프라인 배너로 네트워크 상태를 명확히 전달
  - 메시지 전송 상태 (PENDING 깜빡임, FAILED 에러 아이콘)

[개선필요]
  - DiaryScreen 일기 생성 중 진행률 표시가 CircularProgressIndicator만으로는
    소요 시간을 예측하기 어렵다. 예상 시간이나 진행 단계 표시를 추가할 것.

2.2 시스템과 실제 세계의 일치 (Match Between System and Real World)
--------------------------------------------------------------------------------
[우수]
  - 한국어 자연스러운 표현 사용: "누구와 대화할까요?", "방금 전", "3시간 전"
  - 호감도 레벨 네이밍이 직관적: 낯선 사이 -> 아는 사이 -> 친한 친구 -> 특별한 사이 -> 연인
  - 감정 시스템이 일상적 감정 어휘와 일치 (기쁨, 수줍, 슬픔, 화남 등)

2.3 사용자 통제와 자유 (User Control and Freedom)
--------------------------------------------------------------------------------
[우수]
  - 모든 화면에 뒤로가기 네비게이션 아이콘 제공
  - 대화 초기화 전 확인 다이얼로그
  - 캐릭터 삭제 전 확인 다이얼로그
  - 로그아웃 전 확인 다이얼로그

[개선필요]
  - 메시지 수정/삭제 기능이 없다. 전송 실패 시 재전송만 가능하다.
  - 온보딩 중 건너뛰기(Skip) 옵션이 없어 5단계를 모두 거쳐야 한다.

2.4 일관성과 표준 (Consistency and Standards)
--------------------------------------------------------------------------------
[우수]
  - Material3 컴포넌트를 일관되게 사용
  - 카드 형태(RoundedCornerShape 14~20dp)가 전체적으로 통일
  - TopAppBar 패턴이 모든 하위 화면에서 동일

[개선필요]
  - RoundedCornerShape 값이 14dp, 16dp, 20dp로 혼재되어 있다.
    표준 코너 반지름 세트를 정의할 필요가 있다.

2.5 에러 방지 (Error Prevention)
--------------------------------------------------------------------------------
[우수]
  - 닉네임 입력 시 2~8자 길이 제한
  - VoiceCallScreen 마이크 권한 없을 시 안내 다이얼로그
  - 파괴적 행위(삭제, 초기화, 로그아웃) 전 확인 절차

2.6 태스크 플로우 효율성
--------------------------------------------------------------------------------
캐릭터 추가 -> 대화 시작까지의 흐름이 잘 설계되어 있다:
  - 갤러리에서 캐릭터 선택 -> 바텀시트 상세 -> "내 캐릭터로 추가" -> 즉시 채팅화면
  - HomeScreen에서 캐릭터 카드 탭 -> 즉시 채팅화면
  - 빈 상태에서 명확한 CTA 제공 ("갤러리에서 캐릭터 고르기", "직접 만들기")


================================================================================
3. 접근성 분석
================================================================================

3.1 contentDescription (대체 텍스트)
--------------------------------------------------------------------------------
[우수] 네비게이션 아이콘에 한국어 contentDescription이 적용되어 있다:
  - "뒤로가기" (Icons.AutoMirrored.Filled.ArrowBack)
  - "설정" (Icons.Default.Settings)
  - "캐릭터 추가" (Icons.Default.Add)
  - "음성 대화", "프로필", "메뉴" (ChatScreen TopAppBar)
  - "녹음 중지", "말하기", "통화 종료" (VoiceCallScreen)
  - "닉네임 수정" (SettingsScreen)
  - "접기", "펼치기" (DiaryScreen 과거 일기)

[개선필요]
  - GalleryBannerCard의 ArrowForward 아이콘: contentDescription = null
  - ImageGeneratorBannerCard의 ArrowForward 아이콘: contentDescription = null
  - LoginScreen FeatureRow의 아이콘: contentDescription = null
  - 이 null 값들은 장식용이라면 문제없으나, 카드 자체가 클릭 가능하므로
    TalkBack 사용자를 위해 카드 레벨의 semantics 설명이 필요하다.

3.2 색상 대비 (Color Contrast)
--------------------------------------------------------------------------------
[우수]
  - 핵심 텍스트에 MaterialTheme.colorScheme.onBackground/onSurface 사용
  - 보조 텍스트에 onSurfaceVariant 사용

[개선필요]
  - VoiceCallScreen에서 Color.White.copy(alpha = 0.55f)로 표시되는 안내 텍스트는
    어두운 배경 위에서 대비가 WCAG AA 기준(4.5:1)을 충족하지 못할 수 있다.
  - 호감도 레벨 태그(HomeScreen)에서 affinityColor 위의 텍스트가 같은 색상이므로
    배경 알파(0.15f)와의 대비가 낮을 수 있다. 특히 Lv.3 노란색 계열.

3.3 터치 타겟 (Touch Targets)
--------------------------------------------------------------------------------
Material3 IconButton은 기본 48dp 터치 타겟을 제공하므로 대부분 적절하다.

[개선필요]
  - 채팅 피드백 아이콘(ThumbUp/ThumbDown)의 IconButton이 28dp로 설정되어 있다.
    최소 권장 터치 타겟 48dp에 미달한다. (ChatScreen 788번째 줄)
  - PastDiaryCard의 확장/접기 아이콘이 20dp로 작다. 카드 전체가 클릭 가능하므로
    기능적 문제는 적으나, 아이콘 자체의 가시성이 낮다.

3.4 스크린리더 지원
--------------------------------------------------------------------------------
[개선필요]
  - Canvas로 그려지는 CharacterFace에 semantics 정보가 없다.
    캐릭터의 감정 상태를 TalkBack으로 전달하기 위해 Modifier.semantics {}를
    추가해야 한다.
  - 호감도 LinearProgressIndicator에 진행 값에 대한 설명이 없다.

4. 마이크로인터랙션
================================================================================

4.1 애니메이션 목록 및 품질
--------------------------------------------------------------------------------

[SplashScreen]
  - fadeAnim + scaleAnim: 로고 등장 (0.8->1.0 스케일, 800ms)
  - subtitleFade: 부제목 페이드인
  - bounceY: 로고 박스 무한 바운스 (-15dp, 1000ms)
  - decorFloat: 배경 장식 원 부유 (-8dp~8dp, 2000ms)
  - 미니 표정 행: 개별 지연 바운스 (120ms 간격)
  -> [우수] 브랜딩과 캐릭터성을 효과적으로 전달

[ChatScreen]
  - 메시지 등장: fadeIn + slideInVertically (spring, StiffnessLow)
  - 전송 버튼 스케일 애니메이션 (animateFloatAsState)
  - 레벨업 Lottie 오버레이 (fullscreen)
  - 전송 대기 중 알파 깜빡임 (0.3~1.0, 800ms)
  -> [우수] 챗 인터랙션이 생동감 있음

[GalleryScreen]
  - PresetCard 프레스 애니메이션: scale 0.95f (spring, StiffnessHigh)
  -> [우수] 누르는 느낌의 촉감적 피드백

[VoiceCallScreen]
  - 배경 그라디언트 부드러운 전환 (animateFloatAsState, 600ms)
  - 상태 인디케이터 색상 전환 (animateColorAsState, 400ms)
  - 캐릭터 바운스 (말할 때 800ms, 기본 1400ms)
  - 감정별 스케일 반응 (spring, StiffnessLow)
  - 마이크 펄스 애니메이션 (1.0~1.18, 600ms)
  - SpeakingWaveRow: 7개 바의 파형 애니메이션
  - TypewriterText: 글자 단위 타이핑 효과 (28ms/char)
  -> [우수] 전화 통화 경험을 풍부하게 구현

[LiveCharacter 컴포넌트]
  - Layer 1: 숨쉬기 스케일 (1.0~1.025, 2800ms)
  - Layer 1: 부유감 Y 이동 (0~-8, 3400ms)
  - Layer 1: 미세 회전 (-0.5~0.5도, 4200ms)
  - 감정별 스케일 (spring)
  - 터치 반동 (0.92f, spring DampingRatioMediumBouncy)
  - 센서 기반 시차 효과
  - AGSL Wave Shader (API 33+): 머리카락 물결 효과
  -> [탁월] 캐릭터 생명감 표현의 핵심 컴포넌트

[DiaryScreen]
  - PastDiaryCard: animateContentSize (spring, DampingRatioMediumBouncy)
  -> [양호] 콘텐츠 확장/축소에 부드러운 전환

4.2 전환(Transition) 품질
--------------------------------------------------------------------------------
[AppNavHost]
  - 기본: slideIntoContainer / slideOutOfContainer (300ms)
  - SplashScreen: fadeIn/fadeOut (300ms)
  - DiaryScreen: fadeIn/fadeOut (300ms)
  - VoiceCallScreen: fadeIn/fadeOut (400ms) - 전화 진입감 표현

[평가] 화면 전환이 자연스럽고, 화면 특성에 맞게 전환 방식을 차별화한 점이 좋다.
VoiceCallScreen의 fade 전환은 전화 수신/종료 느낌과 잘 맞는다.

5. 캐릭터 표현 시스템
================================================================================

5.1 3세대 아바타 렌더링 아키텍처
--------------------------------------------------------------------------------
CharacterFaceCanvas.kt에서 세 가지 렌더링 모드를 지원한다:

(1) img: 접두어 - AI 생성 이미지 기반 캐릭터
    - Coil AsyncImage를 통한 원격 이미지 로드
    - 감정별 expressionUrls 맵으로 표정 변환
    - ImageCharacterFace 별도 컴포넌트

(2) v2: 접두어 - Compose Canvas 벡터 캐릭터
    - 12단계 렌더링 파이프라인:
      배경원 -> 헤어뒤 -> 귀 -> 얼굴 -> 앞머리 -> 눈썹 -> 속눈썹 -> 눈 -> 코 -> 볼 -> 입 -> 감정이펙트 -> 악세서리
    - AvatarConfig 기반 커스터마이징 (피부색, 헤어스타일 6종, 눈 스타일 4종, 악세서리 5종)
    - 눈 깜빡임: 3~5초 주기 자동 블링킹
    - 10가지 감정별 눈/입/효과 분기

(3) 레거시 이모지 - 단순 텍스트 이모지 + 컬러 배경
    - CharacterAvatar.fromId()로 폴백 처리

5.2 감정 표현 디테일 (v2 Canvas)
--------------------------------------------------------------------------------
10가지 감정(CharacterEmotion)에 대해 세밀한 시각적 분화가 구현되어 있다:

  NEUTRAL: 기본 애니메풍 눈 (홍채 2단계 + 하이라이트), 작은 미소
  HAPPY: 반달 눈(아래 볼록 호), 넓은 웃음(치아 하이라이트)
  SHY: 시선 오프셋(왼쪽 아래), 볼터치 강화(0.45 알파) + 빗금 볼터치, 오메가입
  SAD: 눈 아래 처짐 + 눈물 방울, 아래로 처진 입, 머리위 우울 구름
  ANGRY: V자 눈썹, 좁은 흰자 + 붉은 홍채, 이빨 돌출, 이마 화남 마크(#)
  SURPRISED: 위로 올라간 눈썹, 큰 흰자 + 작은 동공, O자 입
  LOVE: 하트 동공(Path cubicTo), 볼터치 강화 + 빗금, 하트 미소
  PLAYFUL: 한쪽 윙크(> 모양), 삐죽 웃음 + 혀, 비대칭 표현
  WORRIED: 아치형 눈썹, 시선 약간 아래, 물결 입
  TOUCHED: 반짝이는 큰 눈(큰 하이라이트) + 눈물 반짝, 감동 웃음

[탁월] 각 감정의 시각적 차별화가 명확하고, 애니메이션 스타일의 귀여운 표현이
앱의 캐릭터성과 잘 어울린다. 하트 동공, 눈물 방울, 화남 마크 등 디테일이 뛰어나다.

5.3 악세서리 시스템
--------------------------------------------------------------------------------
5종의 악세서리: 리본, 왕관, 안경, 고양이귀, 꽃 장식
각각 Canvas Path로 정밀하게 구현되어 있으며, 헤어 컬러와 연동된다.

5.4 헤어스타일 시스템
--------------------------------------------------------------------------------
6종: 긴 생머리(하이라이트 포함), 단발, 트윈테일, 포니테일, 짧은 머리, 올림머리
뒤레이어 + 앞머리 분리 렌더링으로 자연스러운 레이어드 효과를 구현한다.

6. 채팅 UX
================================================================================

6.1 메시지 버블 디자인
--------------------------------------------------------------------------------
[우수]
  - 사용자 버블: 오른쪽 정렬, RoundedCornerShape(20, 20, 4, 20) - 우측 하단 뾰족
  - AI 버블: 왼쪽 정렬, RoundedCornerShape(20, 20, 20, 4) - 좌측 하단 뾰족
  - 감정별 버블 색상 변화 + 테두리(1.5dp BorderStroke)로 AI 감정 상태를 시각적으로 전달
  - 다크 모드 대응: isDark 분기로 별도 색상 적용
  - 최대 너비 제한: 사용자 280dp, AI 260dp -> 가독성 확보

6.2 입력 영역
--------------------------------------------------------------------------------
ChatInputBar 컴포넌트:
  - 멀티라인 입력 지원 (최대 4줄)
  - 전송 버튼 스케일 애니메이션
  - ImeAction 기반 키보드 전송

6.3 타이핑 인디케이터
--------------------------------------------------------------------------------
  - TopAppBar에 "입력 중..." 텍스트
  - TypingIndicatorBubble 컴포넌트 (Lottie 기반 추정)
  - 캐릭터 애니메이션 영역에 "생각하는 중..." 텍스트

[우수] 다중 레이어에서 AI 응답 대기 상태를 알려주어 사용자 불안을 효과적으로 완화한다.

6.4 메시지 상태 관리
--------------------------------------------------------------------------------
  - PENDING: 텍스트 알파 깜빡임으로 전송 대기 표현
  - FAILED: 에러 아이콘 + "전송 실패" 텍스트 + "재전송" 버튼
  - 성공: 시간 표시 (한국어 오전/오후 포맷)

[우수] 오프라인 메시지 큐 시스템과 연동되어 네트워크 불안정 시에도
사용자 경험이 끊기지 않는다.

6.5 피드백 시스템
--------------------------------------------------------------------------------
  - AI 메시지에 ThumbUp/ThumbDown 아이콘 (500ms 딜레이 후 fade-in)
  - 피드백 제출 후 비활성화로 중복 방지

[개선필요]
  - 피드백 아이콘의 터치 타겟이 28dp로 너무 작다.
  - 피드백 제출 후 시각적 확인(토스트 등)이 없다.

6.6 캐릭터 애니메이션 영역
--------------------------------------------------------------------------------
ChatScreen 상단에 140dp 높이의 캐릭터 애니메이션 영역을 배치했다.
  - 호감도 레벨별 배경 그라디언트 변화 (Lv.3: 노란, Lv.4: 분홍, Lv.5: 라벤더)
  - LiveCharacter 컴포넌트로 숨쉬기/부유/센서 반응
  - 감정 라벨 텍스트 표시

[평가] 채팅 화면에서 캐릭터 존재감을 확보하면서도 140dp로 적절히 제한하여
채팅 영역을 침범하지 않는다.

7.1 Lottie 애니메이션 활용

프로젝트에 포함된 Lottie 에셋:

  - playful.json, shy.json, surprised.json, touched.json, worried.json: 감정별 배경 효과

배경으로 렌더링한다.

[우수] Lottie를 감정 표현의 보조 레이어로 활용하여, Canvas 캐릭터 + Lottie 배경
조합으로 풍부한 시각적 경험을 제공한다.

7.2 색상을 통한 감정 전달
--------------------------------------------------------------------------------
ChatScreen AI 버블:
  - 감정별 버블 색상 분화 (emotionBubbleLight/Dark 함수)
  - 감정별 테두리 색상 (emotionBorderColor 함수)

VoiceCallScreen 배경:
  - SPEAKING: 아바타 기본색 기반 그라디언트
  - LISTENING: 블루 계열 (#1565C0)
  - PROCESSING: 퍼플 계열 (#6A1B9A)
  - IDLE: 기본색 + 다크 배경

호감도 레벨별:
  - 채팅화면 캐릭터 영역 배경 그라디언트가 레벨에 따라 변화
  - 홈화면 카드의 호감도 프로그레스바 색상 변화

7.3 감정-시각 매핑 체계
--------------------------------------------------------------------------------
감정이 다음 채널을 통해 동시에 전달된다:
  (1) Canvas 얼굴 표정 (눈, 입, 볼, 효과)
  (2) Lottie 배경 이펙트
  (3) 채팅 버블 색상/테두리
  (4) TopAppBar 감정 이모지
  (5) 감정 라벨 텍스트

[탁월] 다중 감각 채널을 통한 감정 전달이 매우 효과적이다.
사용자가 캐릭터의 감정 변화를 놓치기 어렵다.

9.2 화면 계층 분석
--------------------------------------------------------------------------------
깊이 최대 3단계: Home -> Chat -> CharacterProfile -> (VoiceCall | Diary)
대부분의 핵심 기능이 2단계 이내에 접근 가능하다.

[우수]
  - 홈에서 캐릭터 탭 한 번으로 채팅 진입 (1-tap access)
  - 채팅에서 프로필/음성대화 직접 접근 가능 (TopAppBar 액션)
  - 바텀 네비게이션으로 갤러리/설정 즉시 접근

[개선필요]
  - 일기장 접근 경로: Home -> Chat -> Profile -> Diary (3-tap)
    자주 사용할 기능이라면 더 짧은 접근 경로가 필요하다.
  - 캐릭터 카드에서 롱프레스로만 삭제 접근 가능한데,
    이 제스처의 발견가능성(discoverability)이 낮다.
